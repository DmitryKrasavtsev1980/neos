# План реализации системы навигации между панорамами

## 📋 Обзор

Реализация интерактивной системы переходов между панорамами виртуального тура с использованием hotspots, настройками камеры и автовращением.

---

### 2.2 Модификация TourResource.php

Добавить в Repeater::make('members'):
- Hidden::make('id') с автогенерацией UUID
- Fieldset с настройками камеры (yaw, pitch, zoom)
- Fieldset с настройками автовращения (enabled, delay, speed)
- ViewField с кастомным редактором hotspots
- Hidden::make('hotspots') для хранения JSON
